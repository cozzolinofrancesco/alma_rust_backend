II. Alma Overview

    What is Alma?
    Alma is a platform for:

        Managing projects

        Searching scientific data

        Uploading documents

        Building and running AI-powered workflows

    Alma Home Page
    The central hub for:

        Viewing and loading projects

        Accessing main features (Search Data, Upload, Build/Run Workflow Agents)

        Displaying user info (Alma/Roche logos)

        Launching the Alma Assistant (Owl icon)

    Key Features of the Home Page

        Top Navigation Bar – Buttons for:

            Search Data

            Upload

            Build Workflow Agents

            Run Workflow Agents

        Project List – Table showing:

            Name

            Owners

            Creation Time

            Collaborators

        Project Actions – Available options:

            New Project

            Setup Project Structure

            Load Project

        User Information – Alma/Roche logos (top right). Clicking reveals project/user details.

        Alma Assistant – Owl logo (far top right). Opens chat help.

    How to Create a New Project

        Click “New Project.”

        Enter: Project Name + Collaborators.

        Click “Create.”

    How to Set Up Project Structure (One-Time Setup)

        Click “Setup Project Structure.”

        Wait for confirmation message (indicates sub-folders and directories are created).

    How to Load an Existing Project

        Click the project’s name in the Project List.

        Click “Load Project.”

    How to Use the Alma Assistant

        Click the owl icon (far top right).

        Type your question in the chat window.

        Press “Send.”

III. Search Data Window

    Purpose
    Finding and analyzing scientific literature across multiple databases.

    How to Access
    Click “Search Data” on the home page’s top navigation bar.

    Interface Elements

        Search Bar – Enter free-text query.

        Database Selection – Dropdown to choose:

            OpenAlex

            PubMed

            Romine

        Search Button – Executes the query.

        Search Results List – Columns:

            Checkbox (select results for batch interrogation)

            DOI

            Source Title

            Source (database name)

            Abstract (snippet)

            “Show Full Text” link (if available)

            Interrogate Icon (owl) for direct Q&A on that result

        Interrogation Window (appears when you click the owl icon):

            Title (of the selected paper)

            Question Input box

            “Send” button

            “Close” button

    How to Perform a Search

        Enter query in the Search Bar.

        Select target database from Database Selection.

        Click “Search.”

    How to Interrogate Search Results

        Single Resource: Click the owl icon beside its row.

        Multiple Resources: Check boxes beside desired results, then click any owl icon to ask a question that spans all selected items.

    Data Availability by Source

        OpenAlex / PubMed – Usually abstracts only by default.

        Romine – Often provides full-text access.

IV. Upload Tab

    Purpose
    Import PDF documents, run OCR, convert extracted text into LaTeX format for downstream processing.

    Interface Elements

        Upload Area (Left Panel) – Drag-and-drop or “Browse” to select PDFs from your computer.

        Documents List (Center Panel) – Table with columns:

            File Name

            Start Page (for OCR)

            End Page (for OCR)

            “Extract” button (to begin OCR on that file)

            Status (shows OCR progress or completion)

        OCR Model Selection (Dropdown) – Choose between:

            Gemini Flash Fast (Faster, lower accuracy)

            Gemini Pro (Slower, higher accuracy, ideal for complex layouts)

        Preview (Right Panel) – Displays a thumbnail/page preview of the selected PDF.

    Upload & OCR Workflow

        Upload PDFs – Drag files into the Upload Area or click “Browse” to pick.

        Select OCR Model – Use the dropdown to choose “Gemini Flash Fast” or “Gemini Pro.”

        Specify Page Range (Optional) – Enter Start Page and End Page if you want OCR for just a portion.

        Preview Document (Optional) – Click on a file in the list to see a preview.

        Initiate OCR – Click the “Extract” button for each file (or multiple files if the UI allows batch).

        Monitor Status – Watch the “Status” column until OCR completes for each document.

    OCR Models Explained

        Gemini Flash Fast – Prioritizes speed. Suitable for simple layouts or quick checks.

        Gemini Pro – Prioritizes accuracy. Best for scanned books, multi-column layouts, or images with text.

V. Build Workflow Agents Window

    Purpose
    Assemble and configure multi-step, AI-powered agents that operate on your document collections.

    Interface Components

        Collections Section (Left Panel) – Lists your existing document collections. For each:

            Name of collection

            Number of items/documents it contains

            Trash icon (hover → click to empty collection)

        Agent Configuration Area (Right Panel) – Where you build each agent’s pipeline:

            Agent Name – Text field to name and save this workflow.

            Step Configuration – For each step you add, configure:

                Prompt: A free-text instruction that the model will follow.

                (Optional) Image Input: Paste an image if needed for vision-based tasks.

                (Optional) Collection Selection: Choose which document collection to query.

                Output Type Buttons (choose how you want the response formatted):
                • Document (default)
                • Lightbulb (detailed/narrative explanation)
                • Code (returns code snippets)
                • List (bulleted list)

                Model Selection: Dropdown for choosing which AI model to run.

                Run – Triggers the model on that step.

                Copy – Duplicates that step (useful for branching or reusing prompts).

                Download – Exports the step’s output (e.g., as a text file).

            Output Area – Shows the model’s response for each step. Includes:

                Expand/Collapse toggle

                “Retry” button (rerun that single step without changing anything)

        Workflow Controls –

            Add Step – Append another step to this agent.

            New Agent – Clear everything and begin a fresh workflow from scratch.

    How to Create & Run a Workflow Agent

        Click “New Agent.”

        Name Your Agent (in the Agent Name field).

        For Step 1:

            Enter a Prompt (e.g., “Summarize each document in Collection A.”).

            (Optional) Paste Image Input if your task needs it.

            (Optional) Select a Collection from the left panel.

            Choose an Output Type (Document, Lightbulb, Code, or List).

            Pick a Model (e.g., “GPT-4o” or “Gemini Pro”).

            Click Run → Wait for results in the Output Area.

        Add More Steps as needed:

            Click “Add Step.”

            Fill in new prompt, collection, output type, model, etc.

            Click “Run” again.

        Copy Steps if you want to replicate a previous configuration.

        Download Results by clicking the “Download” icon on any step’s output.

    Tips for Building Agents

        Start simple: build a one-step workflow first to ensure it runs correctly.

        Clearly label each step in your prompt (e.g., “Step 1: Identify key metadata”).

        Use List output type when you want bullet points.

        Use Code output type if your next step will parse or execute that code.

        If you need visual context from a PDF page, use the Image Input box.

VI. Run Workflow Agents Window

    Purpose
    Load and execute existing workflow agents against chosen document collections, then inspect or export the results.

    Interface Overview

        Collections Panel (Left) –

            Displays all your document collections (same as in Build Agents).

            Allows selecting up to four collections at once for a given run.

            Toggle icons to show/hide individual documents within each collection.

        Workflow Loading & Configuration (Center) –

            Load Workflow: Dropdown or list to pick a previously saved agent (by name).

            Workflow Details: Shows agent name, number of steps, and model used for each step.

            For each loaded step, you must assign which collection it should operate on.

                The UI will indicate required collections per step (e.g., “Step 2 needs Collection B”).

                There may be a visualization/tree showing dependencies between steps.

            Run Agent button: kicks off the entire pipeline in sequence.

        Results Display (Right) – After running:

            Shows each step’s output in order, with options to:

                Expand/Collapse detailed views

                Copy text to clipboard

                Download responses as files

    How to Run an Existing Agent

        In the Collections Panel, ensure your desired document collections are loaded.

        In Workflow Loading, select the agent you previously saved.

        For each step listed, assign the correct collection (or collections) from the left panel.

            The UI will highlight any missing assignments in red.

        Click Run Agent.

        Watch outputs appear in the Results Display.

        Use “Copy” or “Download” to extract outputs for reporting or further analysis.

    Key Considerations

        Collection Matching: Ensure each step’s prompt is logically mapped to the right collection. A mismatch can cause errors.

        Workflow Preview: Before running, review the step-by-step summary to confirm you understand dependencies.

        Error Handling: If a step fails, examine that step’s prompt, assigned collection, and chosen model. Modify and click “Retry.”

        Iterative Testing: For large datasets, test your workflow on a smaller collection first to verify outputs.
